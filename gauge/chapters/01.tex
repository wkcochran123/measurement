\section{The Primitive Distinction}
\label{se:primitive-distinction}

% The answer: a Fact. Show the Lean definition:
%
%   class Fact where
%     truth : Prop
%     decTruth : Decidable truth
%
% A Fact is a proposition together with a decision procedure. The compiler
% insists on the decision procedure. It will not accept a claim it cannot verify.
%
% Fact.Truth = { truth := true, decTruth := Decidable.isTrue rfl }
% "rfl" means "it follows by reflection." The simplest fact: true is true.
%
% Sidebar: Propositions vs. Facts. A proposition is a claim. A Fact is a
% proposition equipped with a method of decision. "Decidable" has a precise
% meaning: there exists a finite procedure that always terminates with yes or no.
%
% Connect to physics: a measurement is also a decision. The instrument decides:
% this reading is distinguishable from that one.

\begin{gphenom}{Peano-Kushim}
\label{ph:peano-kushim}
\GPhObs The oldest verified act of counting is a 5,000-year-old Sumerian tablet
recording a barley inventory, attributed to a scribe named Kushim.
Peano axiomatized the same act in 1889.
\GPhCon Counting requires a decision procedure: this item is distinct from that one.
The ledger begins with the first verified distinction, not with the first number.
\GPhSeq The compiler's \lean{Fact} is the minimum unit of counting:
a claim that can be verified. Arithmetic is not discovered but built,
one verified distinction at a time.
\end{gphenom}

\section{Counting from Nothing}
\label{se:counting-from-nothing}

% From Fact, build Number:
%
%   inductive Number where
%     | zero : Fact -> Number
%     | one  : Fact -> Number -> Number
%
% Every number carries its justification with it. The Fact inside each
% Number is the witness that the compiler accepted this step. The number
% line is a ledger of accepted decisions.
%
% Sidebar: Peano and Kushim. The oldest act of counting is a 5,000-year-old
% Sumerian tablet. Counting is the oldest technology. The Lean compiler
% re-discovers it from scratch.

\begin{gphenom}{Hume}
\label{ph:hume}
\GPhObs No finite sequence of observed sunrises guarantees that the sun will
rise tomorrow. Hume established this in 1739: induction cannot be
logically justified from finite evidence.
\GPhCon The compiler cannot infer, from $N$ verified facts, that the $(N+1)$th
fact will hold. Every general claim in the ledger is provisional.
\GPhSeq The ledger records what has been witnessed, not what must be.
The \lean{ADMISSIBLE} typeclass does not predict; it only checks
whether a proposed continuation is consistent with what is already recorded.
\end{gphenom}

\section{The Two Orderings}
\label{se:two-orderings}

% The covariant/contravariant duality in Number.le.
% Four cases: zero/zero same truth (covariant), zero/zero different truth
% (contravariant), one/one same truth (covariant recursive),
% one/one different truth (contravariant recursive).
%
% Two ways to count: forward (each step adds) or backward (each step subtracts).
% A clock counts forward. A countdown counts backward. Both are legitimate
% orderings on the same object.
%
% Name the duality: covariant = direction of accumulation;
% contravariant = direction of elimination.
%
% Sidebar: Clocks and clock complements. In digital signal processing,
% a clock is a T/F alternating sequence. Its complement is the same
% sequence with T and F swapped. Together they tile time. The covariant
% ordering corresponds to the clock; the contravariant to its complement.

\section{What the Compiler Carries Forward}
\label{se:what-compiler-carries}

% Introduce CarrierProcess:
%
%   structure CarrierProcess (Carrier: Type) where
%     symbol: Fact
%     value: Number
%     event: Number -> Number
%
% A CarrierProcess is a triple: a witnessed fact, a current count, and
% a rule for moving to the next count. The Carrier type parameter is
% abstract -- the compiler does not yet know what kind of thing is being
% measured.

\begin{gphenom}{Marconi}
\label{ph:marconi}
\GPhObs Guglielmo Marconi's first transatlantic radio transmission in 1901
was three dots -- the letter S in Morse code. The receiver knew it was
a signal because it was distinguishable from silence. Silence itself
was informative: the channel was open.
\GPhCon Silence is an admissible ledger entry. The absence of a signal is
a witnessed distinction: the instrument was present and nothing arrived.
\GPhSeq The \lean{CarrierProcess.symbol} is not always active.
The compiler must accept the null event as a first-class value.
A ledger that records only signals misses half the experiment.
\end{gphenom}
