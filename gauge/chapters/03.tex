\section{The Halting Boundary}
\label{se:halting-boundary}

% ChaitinsNumberSequence:
%
%   inductive ChaitinsNumberSequence where
%     | halting: ChaitinsNumberSequence
%     | nonhalting: ChaitinsNumberSequence
%
% This two-constructor type captures one of the deepest results in
% mathematics: some programs terminate, and some do not, and there is
% no general algorithm to tell which.
%
% Gregory Chaitin's Omega number is the probability that a randomly
% chosen program halts. It is a real number. It is not computable.
% It exists, but the compiler cannot close on it.
%
% PHYSICAL uses ChaitinsNumberSequence as its threshold:
%   threshold: ChaitinsNumberSequence
%   admissible?: ...
%   halted?: ...
%
% The physical threshold is the boundary between what can and cannot be
% verified. This is not a limitation of any particular instrument. It is
% a structural feature of the measurement process itself.
%
% Connection to the text: the Marconi Phenomenon from the instrument --
% "silence is a constraint." The nonhalting case is informative: the
% compiler's refusal to close is data. The measurement is: this program
% does not halt within the observable window.
%
% Sidebar: The halting problem for non-programmers. Imagine asking a
% librarian whether a book mentions itself. Some books do (dictionaries
% often list their own title). Some don't. Now ask: is there a general
% procedure for answering this question for every possible book?
% Turing proved there is not.

% Area is an accumulation type:
%   inductive Area where
%     | t: Area
%     | dt: Area
%

% claim in the device.

% SensingProcess, a clock (a Phenomenon), and an event? function.

%
% MEASURABLE wraps this in a typeclass with an observed relation on Phenomena.
%
% Sidebar: What is a gauge in physics? In gauge theory, a gauge is a
% choice of reference frame that does not change observable predictions.
% Two gauges describe the same physics if they agree on all admissible
% measurements. In the device, the GaugeProcess is the choice: given
% this sensing process and this clock, these events are observable.

\section{The Quantum Jar}

% Jar:
%   inductive Jar where
%     | color: Jar
%     | bang: Jar
%     | superposition: Jar
%
% The most unusual inductive type in the early episodes. Three states:
% color (a classical outcome), bang (an event), and superposition
% (neither yet).
%
% MeesaProcess holds a Jar as a concept. The name is satirical
% (Jar Jar Binks), but the structure is precise: superposition is a

% been made.
%

% the superposition into a color or a bang.
%
% This is the quantum measurement problem, rendered as a typeclass
% constraint. The compiler will not use a Jar value until GUNGAN
% has been invoked to resolve it.
