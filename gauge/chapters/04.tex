% Equivalation:
%   inductive Equivalation where
%     | physics: Equivalation
%     | zero_like: Equivalation
%     | one_like: Equivalation
%
% The Pauli exclusion principle rendered as a type: at each level,
% exactly one of three states is occupied. This is not the spin-1/2
% story from quantum mechanics texts. It is the compiler's version:
% at each level of the tower, each slot holds exactly one occupant.
%
% DigitalProcess: zero and tick. The binary state machine at the
% foundation of all encoding.
%
% Encoding:
%   inductive Encoding where
%     | boot: Encoding
%     | zero: Encoding
%     | one: Encoding
%
% Three opcodes: boot (initialize), zero, one. Every program is a
% sequence of these. This is the minimal instruction set.
%
% EXECUTED wraps this in a typeclass with execute? and output?.
% The compiler can now run instructions.
%
% Sidebar: The instruction set as a measuring instrument. Every CPU
% has an instruction set -- the finite vocabulary of operations it
% can perform. The Encoding type is the minimal instruction set: you
% can boot, set a bit to zero, or set a bit to one. Everything else
% is derived from these three operations.

\section{Abstraction and the Berry Paradox}
\label{se:abstraction-berry}

% Abstraction:
%   inductive Abstraction where
%     | satire: Abstraction
%     | compile: Abstraction
%     | execute: Abstraction
%
% The three levels of abstraction: mock (satire), compile (produce
% executable form), execute (run). The names are deliberately satirical.
%
% Abstraction.le and Abstraction.lt: the ordering is careful because
% of the Berry paradox. The Berry paradox arises when you try to
% define "the smallest number not definable in fewer than N words":
% the definition is self-referential. Abstraction avoids this by
% requiring that the lt ordering terminate -- compile < execute,
% satire is incomparable. No self-reference is introduced.
%
% VALUE wraps this in a typeclass with monad (the abstraction of the
% closure) and lt? (a decidable ordering on abstractions).
%
% Sidebar: The Berry paradox and self-reference. Russell's paradox,
% Godel's incompleteness, Chaitin's Omega, and the halting problem
% are all variations on a single theme: what happens when a formal
% system refers to itself? The Abstraction type navigates this by
% making the reference structure explicit and bounded.
