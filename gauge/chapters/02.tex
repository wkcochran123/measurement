\section{One Rule at a Time}
\label{se:one-rule-at-a-time}

% Introduce DISTINGUISHABLE as the first typeclass contract.
% Every subsequent class is parameterized over (Value: Type) (Carrier: CarrierProcess Value).
%
%   class DISTINGUISHABLE (Value: Type) (Carrier: CarrierProcess Value) where
%     fact: Fact
%     symbol: Type Value
%     distinct? : Prop
%     different? : Type Value -> Prop
%     dec_distinct : DecidablePred different?
%
% Sidebar: What is a typeclass? A contract. When you declare that something is
% DISTINGUISHABLE, you are promising the compiler that you can distinguish things
% of that type. The compiler holds you to the promise.

\begin{gphenom}{Euclid}
\label{ph:euclid}
\GPhObs Euclid's first common notion: things equal to the same thing are equal
to each other. A geometric figure moved across a plane remains the same figure.
The triangle does not become a different triangle by being translated.
\GPhCon The ledger retains its prior entries under transformation. An event
recorded at time $t$ is still recorded after time $t+1$. Irreversibility
guarantees that prior entries cannot be un-witnessed.
\GPhSeq Object permanence is not a metaphysical postulate but a structural
property of the ledger. The \lean{ADMISSIBLE} typeclass enforces this:
a proposed continuation cannot contradict a prior entry. The past is fixed.
\end{gphenom}

\section{The Chain of Admissibility}
\label{se:chain-of-admissibility}

% ADMISSIBLE -> COUNTABLE -> ENCODED -> RESIDUE as progressive tightening.
%
% ADMISSIBLE: adds counting_process and admissible? -- the first explicit
% admissibility predicate.
% COUNTABLE: adds index and bounded? -- events on a number line.
% ENCODED: adds limit_process and encoding? -- comparing sequences.
% RESIDUE: adds cauchy_process and representative? -- equivalence classes.
%
% Courtroom metaphor: ADMISSIBLE = what evidence may be introduced;
% COUNTABLE = how evidence must be numbered; ENCODED = how two pieces
% may be compared; RESIDUE = the verdict.
%
% Sidebar: Cauchy sequences. A sequence where terms get arbitrarily close
% to each other -- converging without naming the limit.

\begin{gphenom}{Berkeley-Galileo}
\label{ph:berkeley-galileo}
\GPhObs Berkeley argued in 1734 that Galileo's law of free fall implies an
instantaneous infinite velocity at the moment of release, which Berkeley
considered an absurdity that undermined the calculus.
\GPhCon The rate at which new facts can be added to the ledger is bounded by
the instrument's resolution. The derivative of the ledger is bounded
by the admissibility rate.
\GPhSeq \lean{COUNTABLE}'s \lean{bounded?} predicate is this constraint made
formal: no sequence of events may exceed the instrument's capacity to
distinguish them. The ledger grows at most as fast as the instrument can witness.
\end{gphenom}

\section{The First Multi-Fact Structure}
\label{se:first-multi-fact}

% Introduce Sample:
%
%   inductive Sample where
%     | initial_condition: Fact -> Limit -> Sample
%     | signal_response: Fact -> Limit -> Fact -> Limit -> Sample -> Sample
%
% A Sample is the first structure that holds more than one Fact.
% Each signal_response appends a new witnessed event to the record.
% The record is ordered and irreversible by construction.
%
% Sample and Limit model the dual structure of observation:
% the thing observed (Limit) and the act of observation (Sample).

\begin{gphenom}{da Vinci-Coulomb}
\label{ph:da-vinci-coulomb}
\GPhObs Da Vinci observed that a block on a rough surface resists motion
until the applied force exceeds a threshold. Coulomb formalized this in 1781:
static friction holds until the threshold is crossed, then yields.
\GPhCon A proposed continuation is not admissible until it exceeds the ledger's
static friction threshold -- the accumulated inconsistency required to force
a new entry. Below the threshold, the ledger absorbs the proposal without yielding.
\GPhSeq The \lean{SlipProcess} models this exactly: the instrument does not record
a new event until the perturbation exceeds its resolution. Measurement is not
continuous. It is a series of threshold crossings.
\end{gphenom}
