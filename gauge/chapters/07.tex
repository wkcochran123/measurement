\section{Three Derivatives}
\label{se:three-derivatives}

% Episode 9: Variation.
%
%   inductive Variation where
%     | newton: Variation
%     | gateaux: Variation
%     | frechet: Variation
%
% Three kinds of derivative, three ways of asking what changes when
% you perturb something:
%
% Newton: the derivative as a limit of secant slopes. The classical
% definition. Works for functions on the real line.
%
% Gateaux: the directional derivative. You fix a direction in an
% infinite-dimensional function space and ask how the functional
% changes in that direction. Used in the calculus of variations.
%
% Frechet: the derivative as a bounded linear operator. The strongest
% notion. If the Frechet derivative exists, the function is well-
% approximated by a linear map near every point.
%
% BigRedDogProcess holds a Variation and a transmute function.
% The name is a reference to Clifford the Big Red Dog -- the idea
% that applying a derivative transforms a function into something
% of a different type, the way Clifford transforms his surroundings
% by being enormously red.
%
% LOCAL: adds theory (a BigRedDogProcess), delta (a Prop -- the
% neighborhood), and experience (a predicate on local behavior).
%
% Sidebar: Why three derivatives? The three correspond to the three
% main strategies in the instrument for approximating the invariant
% field: Newton search (Cauchy sequences), Galerkin projection (finite
% element), and bisection (Cantor construction). Each requires a
% different notion of derivative.
