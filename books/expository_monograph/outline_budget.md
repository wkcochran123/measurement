## Workflow

Each piece of the book goes through an outline loop before any LaTeX writing.

```text
1. Codex outline seed:
   Compute a concept budget, break the piece to subsection/subsubsection depth
   as needed, identify source episodes, cite the relevant bibliography file,
   and state the accepted word band.

2. Antigravity outline pass 1:
   Critique missing concepts, over-budget concepts, under-budget concepts,
   ordering problems, Lean-anchor problems, bibliography needs, and scope
   leakage.

3. Codex outline pass 2:
   Reconcile Antigravity's critique, revise the budget, and tighten the
   restricted writing context.

4. Antigravity outline pass 2:
   Either agree, or name a structured residual. If the residual changes the
   target by more than 15 percent, Codex runs one more outline pass.

5. Codex ratification:
   Mark the outline AGREED and issue exactly one writing prompt for the piece.
```

The normal loop is 3-4 passes per piece after the seed. No piece advances to
LaTeX while its outline status is `OPEN`, `CRITIQUE_REQUESTED`, or
`REVISION_REQUESTED`.
