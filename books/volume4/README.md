# Volume 4 Workspace

This is a non-RYOT workspace for the first-draft pass on Volume 4.

The process is intentionally simple:

1. Outline generation writes `outline.md`.
2. Text generation drafts from that outline into `draft/`.
3. Beastmaster review stays outside the artifacts and checks scope, voice, and claim discipline.

Do not use the active RYOT inboxes, state files, prompt automations, or handoff turns for this work.
