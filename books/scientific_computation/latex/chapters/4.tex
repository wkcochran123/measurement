\chapter{The Tower Turns Around}

\section{Requirements pull backward}

A requirement is a question on reported values.  Let \(S\) be a finite setup domain, \(R\) a report domain, and
\[
                              O:S\to R
\]
a forward observation map.  Let \(Q\) be requirement syntax on \(R\), and separately posit a partial evaluator
\[
       \operatorname{eval}_Q:R\to
       \mathsf{Option}\{\mathsf{yes},\mathsf{no}\}.
\]
Its resolved reading pulls backward to setups:
\[
                 O^*\operatorname{eval}_Q=\operatorname{eval}_Q\circ O.
\]
Construction or observation carries a setup forward to a report; reading asks which setups satisfy a report-side
question.  The requirement does not choose a setup, construct a witness, or perform an experiment.  The evaluator may
return evidenced yes, evidenced no, or no value; the last case leaves \(Q\) unresolved.

Composition reverses:
\[
 S\xrightarrow{O}R\xrightarrow{G}T,\qquad
 (G\circ O)^*\operatorname{eval}_P
   =O^*(G^*\operatorname{eval}_P)
\]
for question syntax \(P\) on \(T\) and its partial evaluator.  The outer evaluator is pulled through \(G\) first and
then through \(O\).
This contravariant reading is distinct from reversing arguments inside a comparison rule.

An admissible fiber is
\[
 F_Q=\{s\in S:\operatorname{eval}_Q(O(s))=\mathsf{some}(\mathsf{yes})\}.
\]
Using the word admissible requires a declared \(Q\).  The set \(F_Q\) is defined even when \(S=\varnothing\), and may
itself be empty for nonempty \(S\).  Claiming that a selectable setup exists requires
\[
                              F_Q\ne\varnothing.
\]
Even that statement is only an existence requirement.  It does not select an element of \(F_Q\); selection and witness
construction belong to the next action.

For a family \((F_i)_{i\in I}\), a global selection claim requires
\[
                         \forall i\in I,\qquad F_i\ne\varnothing.
\]
For a finite explicitly listed family with decidable membership, exhaustive search selects the first member of each
fiber and certifies every choice; no axiom of choice is needed.  An arbitrary family requires a separate selection
principle and still cannot select from an empty fiber.

Tolerance must also be explicit.  A raw metric test
\[
                           d(r,r')\le\varepsilon
\]
is reflexive and symmetric but generally not transitive, so it is not automatically an equivalence relation.  For a
genuine tolerance equivalence, declare a finite bin map \(b_{h,c}:R\to B\), with scale \(h\) and boundary convention
\(c\), and define
\[
                 r\equiv_{h,c} r'
                 \quad\Longleftrightarrow\quad
                 b_{h,c}(r)=b_{h,c}(r').
\]
Equality in \(B\) makes this relation reflexive, symmetric, and transitive.  A desired report bin \(\beta\in B\) gives
\[
 \operatorname{eval}_{Q_\beta}(r)=
   \begin{cases}
   \mathsf{some}(\mathsf{yes}),&b_{h,c}(r)=\beta,\\
   \mathsf{some}(\mathsf{no}),&b_{h,c}(r)\ne\beta,
   \end{cases}
 \qquad
 F_\beta=O^{-1}(b_{h,c}^{-1}(\{\beta\})).
\]
The scale \(h\), cell diameter, boundary convention, and units are part of the requirement.  A bin scale is not
automatically the metric tolerance \(\varepsilon\); their relation must be demonstrated for the chosen geometry.

\paragraph{Worked example 1: a nonempty tolerance fiber (external numerical experiment).}
Let
\[
 S=\{\mathtt a,\mathtt b,\mathtt c\},\qquad
 O(\mathtt a)=1.02,\quad O(\mathtt b)=1.11,\quad O(\mathtt c)=1.27,
\]
and use left-closed bins \(b_{0.1,\mathrm{left}}(r)=\lfloor10r\rfloor\), whose cells have diameter \(0.1\).
For desired bin \(\beta=11\),
\[
                         F_{11}=\{\mathtt b\}.
\]
The fiber is nonempty, so an admissible setup exists.  Its singleton form identifies \(\mathtt b\) as the sole
admissible candidate, but no subsequent setup-selection action has yet been performed.

A bounded filter realizes a finite tolerance read.  Given candidates
\(S_N=[s_1,\ldots,s_N]\), target \(r_*\), tolerance \(\varepsilon\), and budget \(B\le N\), visit
\(i=1,\ldots,B\), compute
\[
 y_i=O(s_i),\qquad \delta_i=d(y_i,r_*),
\]
and retain \(s_i\) exactly when \(\delta_i\le\varepsilon\).  Stop with \textsc{complete} when \(B=N\),
\textsc{budget} when \(B<N\), or \textsc{resolver-domain}.  The certificate contains candidate indices, readings,
residuals, evidenced decisions, retained and rejected slices, \(N,B\), completeness, erasures, and stop reason.  An
empty retained slice means only that no visited candidate passed.  It proves an empty fiber only when \(S_N\) is
certified as a complete enumeration of \(S\) and the run is complete.

Projecting a residual to a pass bit or bin erases information.  Equal residuals do not identify candidates or readings;
equal pass bits erase still more.  The report records the fate of residual, pass, and bin values.

\paragraph{Worked example 2: a requirement can be unsatisfied (external numerical experiment).}
With the same domain and observation map, desired bin \(\beta=14\) gives
\[
                         F_{14}=\varnothing.
\]
The requirement remains a well-formed question even though no supplied setup meets it.  Neither a name nor a choice
principle manufactures a member of an empty fiber.

Requirements may themselves depend on prior requirements.  Represent a finite dependency record as nodes
\((v,Q_v)\) and directed edges \(v\to u\), meaning that resolving \(Q_v\) requires the report for \(u\).  A budgeted
backward traversal uses a worklist initialized with the requested node.  At each visit:

\[
\begin{array}{ll}
1.&\text{remove one unresolved requirement }v,\\
2.&\text{append each unvisited dependency }u\text{ to the worklist},\\
3.&\text{when dependencies are resolved, evaluate the declared resolver for }Q_v,\\
4.&\text{record }v\text{ in the yes, no, or unresolved slice.}
\end{array}
\]

Stop with \textsc{complete}, \textsc{budget}, \textsc{resolver-domain}, or \textsc{dependency-cycle}.  The certificate
contains the requested node, visited nodes and edges, traversal order, all resolver outputs, unresolved worklist,
slices, budget, and stop reason.  It certifies only the visited dependency subgraph.

\paragraph{Worked example 3: finite backward dependency traversal (computation).}
Let requirement \(A\) depend on \(B,C\), and \(C\) depend on \(D\):
\[
                         A\to\{B,C\},\qquad C\to D.
\]
A depth-first backward traversal may visit \(A,B,C,D\).  With budget three, it stops after \(A,B,C\), returns \(D\) on
the unresolved worklist, and cannot resolve \(C\) or \(A\).  The certificate demonstrates the explored edges and budget
stop; it does not infer the missing answer.

\paragraph{Worked example 4: composed reading (computation).}
Let \(O:S\to R\) report an integer and \(G:R\to\{\mathsf{even},\mathsf{odd}\}\) report parity.  For the question
\(P\) whose evaluator returns \(\mathsf{some}(\mathsf{yes})\) on \(\mathsf{even}\) and
\(\mathsf{some}(\mathsf{no})\) on \(\mathsf{odd}\),
\[
 (G\circ O)^*\operatorname{eval}_P(s)
 =\operatorname{eval}_P(G(O(s)))
 =O^*(G^*\operatorname{eval}_P)(s).
\]
The equality demonstrates two descriptions of one pulled-back question.  It does not identify the maps \(O,G\), their
costs, or their report domains.

Cohen's finite-condition method offers a computation-side resonance.  A finite partial assignment
\[
                    p=\{v_1\mapsto a_1,\ldots,v_k\mapsto a_k\}
\]
states requirements on finitely many coordinates.  An extension \(q\supseteq p\) must preserve earlier assignments.
This resembles a dependency ledger whose resolved requirements cannot be silently changed
\cite{cohen1963}.  In forcing vocabulary, a condition set \(D_Q\) is dense precisely when
\[
       \forall p\ \exists q\supseteq p,\qquad q\in D_Q,
\]
where membership in \(D_Q\) means that \(q\) decides or satisfies the declared requirement \(Q\).  The finite worklist
does not demonstrate this quantified density statement.  The analogy stops there: no forcing relation, generic filter,
generic extension, or independence
result follows from a finite worklist.

\paragraph{Worked example 5: physical acceptance window (physics, then interpretation).}
Suppose an apparatus reports a voltage \(O(s)\) for each finite setup.  Physics owns the apparatus, voltage units,
calibration, noise model, and repeated observations.  A bin requirement can classify recorded voltages, but it does not
show that a setup will reproduce the bin on another trial.  Nonempty empirical fibers and physical reproducibility need
their own uncertainty and sampling certificates.

The requirement audit is
\[
 \mathcal D=(S,R,O,Q,\operatorname{eval}_Q,\varepsilon,b_{h,c},h,c,\text{cell diameter},
             \text{dependency graph},\text{resolvers},S_N,\text{candidate indices},
             \text{readings},\text{residuals},\text{decisions},N,B,
             \text{visited subgraph},\text{slices},\text{worklist},
             \text{completeness},\text{stop},\text{erasures},\text{provenance}).
\]
An absent resolver, empty domain, empty admissible fiber, or unvisited dependency is reported directly.

The action ledger closes the section.  Domains, forward maps, question syntax, partial evaluators, metric tolerances,
bin maps, dependency edges, candidate lists, and budgets are \emph{posited}.  Pullback identities, bin-equivalence
laws, coverage and exclusivity invariants, completeness implications, finite exhaustive-selection correctness, and
quantified nonemptiness checks are \emph{demonstrated}.  Actual traversal order, visited nodes, worklist, stop reason,
resolver outputs, fiber membership, residual comparisons, and dependency answers are \emph{read} through
contravariant questions on covariant forward maps.  Arbitrary or global selection, witness action, physical
reproducibility, forcing conclusions, and answers
outside the visited subgraph remain \emph{reserved}.  Requirements pull backward; actions that satisfy them come later.

\section{Witnesses run forward}

A requirement, an existence statement, a selection, and a witness are four different records.  Retain the setup and
report domains \(S,R\), forward map \(O:S\to R\), question syntax \(Q\), and partial evaluator
\[
 \operatorname{eval}_Q:R\to
 \mathsf{Option}\{\mathsf{yes},\mathsf{no}\}.
\]
The requirement read is contravariant:
\[
                 O^*\operatorname{eval}_Q=\operatorname{eval}_Q\circ O.
\]
Its admissible fiber is
\[
 F_Q=\{s\in S:\operatorname{eval}_Q(O(s))
                    =\mathsf{some}(\mathsf{yes})\}.
\]
The statement \(F_Q\ne\varnothing\) establishes existence.  A selector action must then produce a particular
\(s\in F_Q\).  Only after that action can forward construction package a witness
\[
 w=\operatorname{witness}(s,y,c_O,c_Q,c_D),
\]
where \(y=O(s)\), \(c_O\) certifies the forward evaluation, \(c_Q\) is the evidenced yes-answer, and \(c_D\) records
dependency certificates.  Neither the requirement nor nonemptiness contains this record.

For a finite candidate list \(S_N=[s_1,\ldots,s_N]\), a budgeted witness search visits at most \(B\le N\) candidates.
For each visited \(s_i\):
\[
\begin{array}{ll}
1.&y_i\leftarrow O(s_i),\\
2.&a_i\leftarrow\operatorname{eval}_Q(y_i),\\
3.&\text{append }(i,s_i,y_i,a_i)\text{ to yes, no, or unresolved slice},\\
4.&\text{on the declared first-yes policy, construct }w_i\text{ and stop.}
\end{array}
\]
Stop reasons are \textsc{witness}, \textsc{complete-no}, \textsc{budget}, and \textsc{resolver-domain}.  The
certificate contains candidate indices, forward reports, evaluator answers, all slices, selected index when present,
budget, completeness status, erasures, and stop reason.  A budget stop with no yes-answer does not prove \(F_Q\) empty.
A complete-no result proves emptiness only when \(S_N\) is a certified complete enumeration of \(S\).

\paragraph{Worked example 1: finite witness search (computation).}
Let \(S=\{2,3,4,5\}\), \(O(s)=s^2\), and let \(Q\) ask whether the report exceeds \(15\).  In list order, the reports
are \(4,9,16,25\).  A first-yes policy selects \(s=4\) and returns
\[
 w=\operatorname{witness}(4,16,[16=4^2],[16>15],c_D).
\]
The backward requirement identifies the fiber \(\{4,5\}\); the forward action selects one member according to the
declared list order.  A different selection policy may return \(5\) without changing the requirement.

This finite exhaustive selection uses the explicit list and evidenced evaluator; it needs no axiom of choice.  Selecting
simultaneously from an arbitrary family of nonempty fibers is a separate global premise and remains reserved.

Dependencies require an exact two-pass finite algorithm.  First traverse edges backward from the requested target,
record the reverse dependency slice, reject missing predecessors, test acyclicity, and compute a topological order with
predecessors before consumers.  Then, for each node in that order:
\[
\begin{array}{ll}
1.&\text{wait until every predecessor certificate is present},\\
2.&\text{form a cache key from inputs, predecessor results, policies, and versions},\\
3.&\text{if an entry exists, run its declared checker and reuse only on success},\\
4.&\text{otherwise spend construction budget, run the node builder, run the checker,}\\
5.&\text{memoize only a checked result and append the node to the new or reused slice.}
\end{array}
\]
Stops \textsc{missing-dependency}, \textsc{checker-failure}, \textsc{budget}, and \textsc{dependency-cycle} return the
unresolved frontier.  None proves an admissible fiber empty.  The run ledger slices nodes into newly constructed,
verified-reused, checker-failed, and unresolved rows.

\paragraph{Worked example 2: diamond dependency and memoized reuse (computation).}
Let
\[
 A\leftarrow\{B,C\},\qquad B\leftarrow D,\qquad C\leftarrow D.
\]
The reverse slice has four nodes, and one valid forward order is
\[
                              D,B,C,A.
\]
With an empty cache and sufficient budget, the run invokes four builders; \(D\) is constructed once and its checked
certificate is consumed by both \(B\) and \(C\).  If a valid \(D\) entry is preloaded, the run performs one cache
verification and three new constructions, for \(B,C,A\).  The ledger reports exactly three new results, one verified
reuse, and the dependency edges each consumer checked.

\paragraph{Worked example 3: cache invalidation and erasure (computation).}
A cache entry is invalid when any dependency result, builder version, checker version, policy, configuration,
forward map \(O\), or evaluator changes.  Matching a node name alone is unsound.  A compact hash key is acceptable only
under an explicit collision-resistance or collision-checking assumption; hash equality is not mathematical identity.
Storing only the target result may preserve a value while erasing construction trace, checker trace, and cost.  The
audit must record each such erasure rather than treating a cache hit as a complete historical witness.

Turing's framework separates executable evidence from oracle assertion.  For a declared deterministic transition
system and encoded input, a finite halting trace
\[
                c_0\to c_1\to\cdots\to c_m=\mathsf{halt}
\]
is an executable run-specific witness: every transition and the final halt condition can be checked.  An assertion
\(\mathcal H(M,x)\) supplied by an oracle without such a trace is openly posited, not constructed.  For an effective
universal machine model, Turing's result rules out a total computable procedure that correctly decides halting for
every encoded machine-input pair~\cite{turing1936}.  It does not invalidate a finite halting trace for one run, and
such a trace witnesses only the positive halting case.

\paragraph{Worked example 4: trace witness versus oracle assertion (computation).}
Consider a finite transition rule that decrements a positive counter and halts at zero.  From three, the trace
\[
                         3\to2\to1\to0\to\mathsf{halt}
\]
is a checkable witness under the declared rule.  The bare assertion \emph{this run halts} may be correct, but without
the rule and trace it is only an assertion.  Conversely, a finite budget stop before halt is not evidence that the run
never halts.

\paragraph{Worked example 5: apparatus witness (physics, then interpretation).}
Suppose a setup produces a voltage inside a declared acceptance bin.  Physics owns the apparatus, calibration, units,
noise model, and repeated measurements.  A computational witness can package the selected setup, recorded voltage, bin
decision, and acquisition certificate.  It does not establish that every future trial will agree or that the voltage
has another physical name.  Those conclusions need separate experimental evidence.

The witness audit is
\[
 \mathcal W=(S,R,O,Q,\operatorname{eval}_Q,S_N,N,B,\text{selection policy},
             \text{target node},\text{dependency graph},\text{reverse slice},
             \text{acyclicity result},\text{topological order},\text{unresolved frontier},
             \text{builders},\text{checkers},\text{builder/checker versions},
             \text{policies},\text{configuration},\text{map/evaluator versions},
             \text{memo keys},\text{hash assumptions},\text{cache entries},
             \text{cache hits},\text{verification results},\text{budget spent},
             \text{reports},\text{answers},\text{slices},\text{selected setup},
             \text{witness},\text{construction/checker traces},\text{costs},
             \text{erasures},\text{stop},\text{provenance}).
\]
Missing dependencies, unresolved answers, stale memo entries, partial candidate coverage, and oracle assumptions are
reported directly.

The action ledger closes the section.  Domains, maps, question syntax, evaluators, candidate order, selection policy,
dependency graph, builders, checkers, budgets, versions, hash assumptions, and memo policy are \emph{posited}.
Topological-order validity, traversal invariants, cache-verification implications, certificate composition, and the
fact that a completed witness satisfies its pulled-back requirement are \emph{demonstrated}.  Actual reverse slice,
traversal order, visited nodes, frontier, stop reason, reports, answers, cache hits, checker outputs, costs, and fiber
membership are \emph{read}.  The witness is the covariant action and result satisfying a contravariantly pulled
requirement; it is not the requirement itself.  Arbitrary global selection, unsupported oracle answers, future
physical reproducibility, and claims beyond the visited
dependencies remain \emph{reserved}.  Requirements pull backward; witnesses run forward only after selection acts.

\section{Two-pass calibration}

A two-pass calibration earns a name by surviving an exchange of roles.  Let three labels be \(X,Y,Z\).  Pass one
returns and verifies two direct values \(x_1,y_1\), then forms an explicit composite
\[
                              z_\Sigma=\Sigma_1(x_1,y_1).
\]
Pass two rotates the roles: it returns and verifies \(y_2,z_2\), then reconstructs
\[
                              x_\Sigma=\Sigma_2(y_2,z_2).
\]
The maps \(\Sigma_1,\Sigma_2\), their parameters, budgets, stopping rules, scales, and comparison resolution must be
registered before either pass is evaluated and must not depend on an outside target.

Three comparisons close the protocol:
\[
 y_1\equiv_\varepsilon y_2,\qquad
 z_\Sigma\equiv_\varepsilon z_2,\qquad
 x_\Sigma\equiv_\varepsilon x_1.
\]
The first checks the direct overlap.  The second checks the pass-one reconstruction against a pass-two direct value.
The third checks the pass-two reconstruction against the pass-one direct value and closes the round trip.  A shared
name is licensed only after all three comparisons pass.  Two direct values and one composite are recorded at each pass;
the composite is never silently promoted to a direct reading.

Construction runs forward:
\[
 (x_1,y_1)\mathrel{\overset{\Sigma_1}{\longmapsto}}z_\Sigma,\qquad
 (y_2,z_2)\mathrel{\overset{\Sigma_2}{\longmapsto}}x_\Sigma.
\]
Requirements read contravariantly.  If \(F\) maps the complete pass inputs to the three comparison pairs and
\(q_\varepsilon\) asks whether a pair agrees at the declared resolution, then
\[
                         F^*q_\varepsilon=q_\varepsilon\circ F.
\]
The comparison question does not construct a report, and the forward maps do not choose their acceptance criterion.

Neither composite map is assumed injective.  Distinct direct pairs may occupy one composite fiber:
\[
 \Sigma_1(x,y)=\Sigma_1(x',y')\not\Rightarrow(x,y)=(x',y').
\]
The pass ledger therefore retains direct pairs, composite values, and fiber evidence separately, and records any
erasure caused by keeping only a composite.  This is a computational handoff between finite records, not a physical or
quantum superposition.

\paragraph{Worked check 1: exact finite role rotation (external numerical design).}
Take direct values \(x_1=2,y_1=3\) and preregister
\[
                         \Sigma_1(x,y)=x+y.
\]
Then \(z_\Sigma=5\).  Pass two directly returns \(y_2=3,z_2=5\) and uses the preregistered inverse reconstruction
\[
                         \Sigma_2(y,z)=z-y,
\]
giving \(x_\Sigma=2\).  All three comparisons close exactly.  This demonstrates the protocol shape; it is not the
instrument's measured calibration and carries no physical interpretation.

The actual instrument uses two finite numerical routes over shared calibration data
\[
                        C=18,\qquad \text{target}=5,\qquad
                        d_*=\sqrt{C/\text{target}}=\sqrt{18/5}.
\]
The current report directly certifies the two route endpoints and the jar.  It does not by itself print every
\(X,Y,Z\) role-rotation entry above; the full three-role certificate remains a calibration requirement until those
direct/composite records are emitted.
The direct \(1\to3\) route evaluates the measured second-variation formula at \(d_*\) and reports
\[
             d=137011290548979455469\qquad\text{at scale }10^{18}.
\]
The stepped \(1\to2\to3\) route carries its residue through an intermediate quasi-Newton descent and reports
\[
             s=137011290753751157155\qquad\text{at scale }10^{18}.
\]
Its finite count trace is
\[
\begin{array}{c|c|c}
\text{count}&\text{distance report}&\text{inverse report}\\
\hline
0&2/1&129.6\\
1&17/9&137.7\\
2&\approx1.897309&\approx137.016\\
3&\approx1.897366&s/10^{18}.
\end{array}
\]
Mediant/continued-fraction, Newton/BFGS, and residue-carrying secant realizations provide separately declared stepped
algorithms.  Agreement of their displayed endpoint does not identify their traces or costs.

\paragraph{Worked check 2: path comparison at declared resolution (instrument computation).}
The scaled discrepancy is
\[
 |d-s|=204771701686,\qquad
 \frac{|d-s|}{10^{18}}
 =2.04771701686\times10^{-7}.
\]
The scaled integers are not equal.  Their decimal reports agree to nine digits, and the discrepancy is below the
count-three resolution.  Let \(b_3\) be the preregistered finite partition whose owned cell is the count-three jar, and
write
\[
                        a\equiv_3 b\quad\Longleftrightarrow\quad b_3(a)=b_3(b).
\]
This is an equivalence induced by equality of bin labels; for these reports, \(d\equiv_3s\).  The house slogan
\(1\to3=1\to2\to3\) abbreviates \(d\equiv_3s\), not integer equality and not identity of algorithms.

The one discrepancy \(\Delta=|d-s|/10^{18}\) is not a variance estimate.  Statistical variance requires at least
\(n\ge2\) comparable repeated discrepancies \(\Delta_1,\ldots,\Delta_n\):
\[
 \bar\Delta=\frac1n\sum_{j=1}^n\Delta_j,\qquad
 s_\Delta^2=\frac1{n-1}\sum_{j=1}^n(\Delta_j-\bar\Delta)^2.
\]
Inference from \(s_\Delta^2\) additionally requires a declared sampling model, stability assumptions, and treatment of
dependence.  The direct and stepped routes share calibration inputs and are not automatically independent.  For random
reports \(D,S\),
\[
 \operatorname{Var}(D-S)=\operatorname{Var}(D)+\operatorname{Var}(S)
                         -2\operatorname{Cov}(D,S).
\]
This probabilistic covariance is distinct from categorical covariance of forward maps.  No statistical variance,
covariance, or uncertainty interval has been computed by the current two-route comparison.

The owned result is the ordered-wall jar written
\[
                              [129.6,137.7].
\]
The word open is the repository's metaphor for unresolved content, not topological interval notation.  Both finer
reports near \(137.011290\) fall between the ordered walls, but the instrument hands over the jar rather than either
point.

\paragraph{Worked check 3: wall and ownership audit (instrument computation).}
The lower and upper walls come from the first two finite stepped reports, \(2/1\mapsto129.6\) and
\(17/9\mapsto137.7\).  Their order is checked, the count-three stop is recorded, and both direct and stepped endpoint
reports are compared against the walls.  These checks establish the owned bracket and path agreement at its
resolution.  They do not establish agreement with an external physical constant.

Richardson extrapolation remains conditional.  The direct and stepped values arise from different algorithms; no
common family \(A(h)\), refinement ratio \(r\), or error order \(p\) is established.  Under the counterfactual
assumptions \(D=A(h)\), \(S=A(h/2)\), one could write
\[
                           A_R=S+\frac{S-D}{2^p-1}.
\]
Those sensitivity values depend on the unestablished order and orientation.  Licensing the method requires one
implemented ordered \(h\)-family, at least three refinement levels, observed-order estimation, and stability under
further refinement.  A machine/configuration/cost index is one proposed candidate for \(h\), but it requires an
implemented ordering and an error model.  Greater budget or cost is not automatically finer resolution.  The current
direct and stepped pair is therefore invalid for Richardson extrapolation.  Until a qualifying family exists, no
extrapolate is a measurement, uncertainty bound, or owned result.

\paragraph{Worked check 4: target-dependent transition rejected (adversarial test).}
Suppose a proposed composite map is adjusted after seeing a desired number \(t\), for example
\[
                         \widetilde\Sigma_1(x,y)=t.
\]
It will reproduce \(t\) regardless of the direct readings.  The numerical comparison may pass, but preregistration and
target-independence fail, so calibration is rejected.  Agreement manufactured by the transition is not path
independence.

Each route and pass has an independent budget.  A pass certificate records direct values and their verification,
composite values, map definitions and versions, inputs, scales, update traces, stopping rules, budgets spent, residuals,
comparison decisions, erasures, and provenance.  Stops are \textsc{complete}, \textsc{budget},
\textsc{missing-direct}, \textsc{comparison-unresolved}, \textsc{overlap-failure},
\textsc{reconstruction-failure}, \textsc{closure-failure}, \textsc{version-mismatch}, and
\textsc{domain-error}.  Any noncomplete stop returns the unresolved frontier;
it does not license the shared name.

The calibration audit is
\[
\begin{aligned}
\mathcal C={}&(X,Y,Z,\text{role assignments},\text{overlap identities},
\Sigma_1,\Sigma_2,\text{versions},\text{preregistration},
\text{target-independence},\\
&\text{pass-one direct/composite records},\text{pass-two direct/composite records},
\text{overlap},\text{reconstructions},\text{all residual decisions},\\
&d,s,\text{scale},\text{raw discrepancy},\text{resolution relation},
\text{bin-map version},\text{discrepancy-bin version},\text{jar walls},\\
&\text{conditional statistical assumptions/results},
\text{budgets},\text{traces},\text{stops},\text{unresolved frontier},
\text{erasures},\text{provenance}).
\end{aligned}
\]

\paragraph{Descent experiment: parity requirements pull backward and witnesses run forward.}
For a Boolean bond chain \(C=(b_0,\ldots,b_{n-1})\) and proposed initial state \(q\), the Anderson-labelled forward
transform propagates
\[
 T_C(q,0)=q,
 \qquad
 T_C(q,i+1)=T_C(q,i)\mathbin{\mathsf{xor}}b_i.
\]
The backward requirement is even loop parity.  The code proves that every assignment satisfying the interior bonds
coincides with \(T_C(q,\cdot)\), and hence that even parity admits a global extension while odd parity does not.  The
canonical ordered loop returns true; the disordered loop returns false.  Its bounded trace traverses the bond list and
checks closure at length \(n\), recording unmatched endpoint parity on failure.  Thus the commuting test is
\(T_C(q,n)=q\), and the residual after discharging the interior equations is one parity bit.  No disordered material,
wave function, or conductivity is consumed; ``Anderson'' names this finite extension obstruction.

\paragraph{Descent experiment: two-anchor Celsius calibration.}
The Celsius--Lagrange experiment uses an unrestricted integer scale record
\(X=(r_0,r_1,d_0,d_1)\in\mathbb Z^4\) and integer affine interpolation
\[
 T_X(r)=d_0+\frac{(r-r_0)(d_1-d_0)}{r_1-r_0},
\]
