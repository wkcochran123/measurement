\section{Second differences}

An indexed sample ledger is
\[
\mathcal F=[(x_0,f_0),\ldots,(x_{N-1},f_{N-1})],
\]
with strictly increasing coordinates and values in a declared arithmetic domain.  At an interior index
\(1\leq k\leq N-2\), the unscaled second difference is
\[
                         \Delta^2f_k=f_{k+1}-2f_k+f_{k-1}.
\]
The lower, middle, and upper roles are positional: \(f_{k-1},f_k,f_{k+1}\).  Reordering samples or substituting three
unindexed values changes the operation.

On a uniform grid \(x_k=x_0+kh\), \(h>0\), the centered approximation is
\[
                         D^{(2)}_hf_k=\frac{f_{k+1}-2f_k+f_{k-1}}{h^2}.
\]
If a sampled function has four continuous derivatives near \(x_k\), Taylor expansion gives
\[
 D^{(2)}_hf_k=f''(x_k)+\frac{h^2}{12}f^{(4)}(\xi_k)
\]
for a point \(\xi_k\) in the stencil interval.  Thus second-order truncation requires smoothness and a demonstrated
bound on \(f^{(4)}\).  Three numbers alone do not provide that bound or identify a derivative.

For a nonuniform grid, let \(h_-=x_k-x_{k-1}>0\) and \(h_+=x_{k+1}-x_k>0\).  The separate three-point stencil is
\[
D^{(2)}_{\rm nu}f_k=
\frac{2}{h_-+h_+}
\left(\frac{f_{k-1}}{h_-}
-\left(\frac1{h_-}+\frac1{h_+}\right)f_k
+\frac{f_{k+1}}{h_+}\right).
\]
Using the uniform formula on unequal spacing is a model error, not a small implementation detail.  Its truncation
order depends on mesh regularity and smoothness and must be demonstrated for the declared grid family.

Exact integer arithmetic computes \(\Delta^2f_k\) without rounding, subject to resource growth.  Exact rational
arithmetic computes scaled stencils after positive-denominator normalization and cross-products.  Floating arithmetic
introduces rounding and possible cancellation:
\[
\widehat{\Delta^2f_k}
=\operatorname{fl}\!\left(\operatorname{fl}(f_{k+1}-2f_k)+f_{k-1}\right).
\]
The certificate records evaluation order, format, rounding mode, exceptional values, and an error analysis.  Algebraic
equivalence over exact numbers does not guarantee bitwise equality under floating evaluation.

Boundary indices \(k=0,N-1\) lack one centered neighbor.  Valid policies include stopping with
\textsc{boundary}, using a separately derived one-sided stencil with enough samples, supplying ghost values through
a declared boundary model, or restricting output to interior indices.  Silent wraparound asserts periodic boundary
conditions; silent padding asserts a value outside the sampled domain.

The iteration algorithm traverses interior indices, slices the ledger into overlapping triples, validates spacing,
and emits
\[
\mathcal D=[(k,x_k,f_{k-1},f_k,f_{k+1},c_-,c_0,c_+,d_k)].
\]
Here \(c_-,c_0,c_+\) are the coefficients actually consumed and \(d_k\) the computed result.  Stored coefficients that
are never multiplied into the result are metadata, not evidence that a stencil used them.  Replay reconstructs each
arithmetic expression from consumed coefficients and sampled values.

\paragraph{Worked example 1: exact uniform difference (computation).}
For \(f_k=k^2\) at \(k=1\),
\[
                         f_0=0,\quad f_1=1,\quad f_2=4,\qquad
                         \Delta^2f_1=4-2+0=2.
\]
With \(h=1\), the scaled value is \(2\).  This exact arithmetic row agrees with the second derivative of the declared
quadratic, but the general derivative implication still depends on the sampling model.

\paragraph{Vacuum draw: acceleration as a filtered second-difference transform (computation).}
The acceleration experiment runs the preceding arithmetic rather than borrowing its name.  Its domain is a finite
ordered list of integer positions, \texttt{Track}, and its codomain is a ledger of pairs consisting of an interior index and
a signed residual.  The transform first takes adjacent differences, takes adjacent differences again, and filters out
zeros:
\[
 T_{\rm acc}(x_0,\ldots,x_n)
 =\bigl[(i,\ x_{i+2}-2x_{i+1}+x_i):
             x_{i+2}-2x_{i+1}+x_i\ne0\bigr].
\]
The run returns \(|T_{\rm acc}|\).  The straight input \((0,2,4,6)\) yields an empty ledger and stops with \(0\);
the square sequence \((0,1,4,9,16)\) yields residual \(2\) at all three interior positions and stops with \(3\).
The control predicate \texttt{isCoasting} is false on the latter, so the zero filter and its failure edge are observable.
For the bent trace the intermediate first-difference list is \((1,3,5,7)\), the second-difference list is
\((2,2,2)\), and the retained indices are \(0,1,2\).  For a list with fewer than three samples, repeated differencing
returns an empty list; that is a completed finite result under this definition, not evidence that a sparsely sampled
physical trajectory has zero acceleration.  A detector threshold would also replace the exact test \(d\ne0\) with a
new comparison and could change which entries survive.
Keeping only the count \(3\) erases the residual signs and magnitudes.  Under the identity representation on a
unit-spaced integer grid, the recorded residual is exactly
the unscaled \(\Delta^2x_i\) printed above; that square commutes by arithmetic replay.  It does not commute with
\(d^2x/dt^2\) until sampling times, units, a scale \(h^{-2}\), regularity, and a convergence argument are added.

\paragraph{Worked example 2: cancellation and scale (computation).}
For values \(10^{20},10^{20}+1,10^{20}+4\), exact integer arithmetic returns \(2\).  A floating format unable to
distinguish unit increments near \(10^{20}\) may first round all three samples together and return \(0\).  Reporting
the arithmetic model is therefore part of the value.

\paragraph{Counterexample 3: unequal spacing with uniform coefficients (computation).}
Let \(x=(0,1,3)\) and \(f(x)=x^2\), giving values \((0,1,9)\).  The unscaled uniform expression gives \(7\), while
the nonuniform formula gives \(2\), the exact second derivative of this quadratic.  A three-point data shape does not
license uniform-grid coefficients.

\paragraph{Counterexample 4: coefficients stored but not consumed (computation).}
A report may list \((1,-2,1)\) while its result was computed as \(f_{k+1}-f_k\).  The metadata resembles a second
difference, but arithmetic replay fails.  The certificate must trace coefficient consumption, not merely coefficient
presence.

\paragraph{Counterexample 5: boundary wraparound changes the domain (computation).}
At \(k=0\), using \(f_{N-1}\) as the lower sample creates a periodic stencil.  Unless periodicity was declared and
validated, the result belongs to a different problem.  The correct status is \textsc{boundary} or a declared
one-sided method.

Budgets distinguish samples parsed, indices traversed, coefficient generation, exact arithmetic growth, floating
operations, cross-products, storage, replay, and error-bound evaluation.  Stops include \textsc{complete},
\textsc{insufficient-samples}, \textsc{index-domain}, \textsc{boundary}, \textsc{nonmonotone-grid},
\textsc{nonuniform-grid}, \textsc{zero-spacing}, \textsc{coefficient-failure},
\textsc{arithmetic-budget}, \textsc{bit-growth}, \textsc{overflow}, \textsc{nonfinite-value},
\textsc{error-bound-unavailable}, and \textsc{replay-failure}.

A certificate records raw ordered samples, index and boundary domain, grid classification, exact spacings, generated
and consumed coefficients, arithmetic model and evaluation order, every product and sum, exact or rounded outputs,
rounding and truncation bounds, iterative triples, projections and erased fields, budgets, stops, checked scope,
unresolved frontier, versions, snapshot hash, configuration, protocol, run identity, platform, deterministic inputs,
and declared nondeterministic inputs.

Comparison reports independent rows.  Exact same-number compares exact outputs after typed conversion.  Resolution
equality compares labels under a declared quantizer.  Uncertainty compatibility compares declared arithmetic and
sampling regions.  Same-process additionally requires matching samples, indices, grid and boundary models,
coefficients, evaluation order, arithmetic, iteration trace, resources, configuration, and provenance.

Governance fixes sample schema and order, index domain, grid and boundary policies, stencil and coefficient generator,
arithmetic model, evaluation order, smoothness and error assumptions, iteration and slicing, budgets, stop priority,
comparison relations, and certificate grammar.  A changed field begins a new report.

This operator is computation-owned.  It is not by itself a field equation, physical second variation, curvature,
force, mass, or coupling.  Those names require a world model and covariant apparatus action with calibration,
interaction trace, back-action, uncertainty, and alternative causes.  A three-point value alone licenses none.

The action ledger is exact.  Samples, ordering, grid, boundary policy, stencil, arithmetic, smoothness assumptions,
error model, algorithms, budgets, and certificate grammar are \emph{posited}.  Exact difference identities,
nonuniform coefficient identities, conditional truncation bounds, iteration and coefficient-consumption implications,
error propagation, and certificate implications are \emph{demonstrated}.  Samples, spacings, coefficients, arithmetic
events, outputs, errors, resources, stops, and provenance are \emph{read}.  A derivative without smoothness and scale,
uniform accuracy on a nonuniform grid, periodicity from wraparound, an operation from stored metadata, field or
curvature meaning, force inference, and every physical name remain \emph{reserved}.
\section{Physics field equations}

Maxwell's equations are a physical model for fields on a declared spacetime domain:
\[
\begin{aligned}
\nabla\cdot\mathbf E&=\rho/\varepsilon_0,&
\nabla\cdot\mathbf B&=0,\\
\nabla\times\mathbf E&=-\partial_t\mathbf B,&
\nabla\times\mathbf B&=\mu_0\mathbf J+\mu_0\varepsilon_0\partial_t\mathbf E.
\end{aligned}
\]
In SI units, \(\mathbf E\) is volts per metre, \(\mathbf B\) tesla, \(\rho\) coulombs per cubic metre, and
\(\mathbf J\) amperes per square metre.  The equations require a spatial domain, time interval, sources, initial
conditions, boundary conditions, and constitutive relations.  A field solution is conditional on all of them.

In material media, constitutive laws such as
\[
                         \mathbf D=\varepsilon\mathbf E,\qquad
                         \mathbf B=\mu\mathbf H,\qquad
                         \mathbf J=\sigma\mathbf E
\]
introduce measured, possibly tensor-valued, frequency-, temperature-, and history-dependent parameters.  Vacuum
relations cannot be substituted silently for a material apparatus.

A London model for a superconducting region may be written
\[
\partial_t\mathbf J_s=\frac{n_sq_s^2}{m_s}\mathbf E,\qquad
\nabla\times\mathbf J_s=-\frac{n_sq_s^2}{m_s}\mathbf B.
\]
Combined with Maxwell equations under stated assumptions, it yields magnetic penetration with characteristic length
\[
                         \lambda_L=\sqrt{\frac{m_s}{\mu_0n_sq_s^2}},
\qquad
\nabla^2\mathbf B=\lambda_L^{-2}\mathbf B
\]
in an idealized homogeneous interior.  Meissner expulsion is an empirical and model-dependent magnetic response,
requiring temperature, material phase, geometry, preparation history, applied field, and boundary data.  It is not
the Boolean statement \(\nabla\cdot\mathbf B=0\).

Finite-volume discretization integrates conservation laws over cells.  Electric flux through a cell boundary is
balanced against enclosed charge; magnetic face fluxes are arranged so discrete divergence can be monitored or
preserved.  Finite differences instead approximate derivatives on a declared grid.  Both require oriented geometry,
metric factors, material interfaces, boundary conditions, and time-stepping rules.  A three-point second difference
is one local stencil, not Maxwell's system.

For a linearized discrete problem,
\[
                         A_hu_h=b_h,
\]
the solver iterates residuals \(r_k=b_h-A_hu_k\) and stops under a declared norm and tolerance.  Nonlinear constitutive
or material models produce \(F_h(u_h)=0\), requiring a declared linearization, step acceptance, and globalization
policy.  Algebraic convergence of \(r_k\) is solver verification; it does not validate the physical model.

Divergence constraints receive their own rows.  A computed magnetic field reports
\[
                         \eta_{\rm div}=\|D_h\mathbf B_h\|
\]
in a declared norm and scale.  Small \(\eta_{\rm div}\) is a numerical constraint residual.  It is not exact zero
unless exact arithmetic and a structural preservation identity demonstrate that result, and it does not establish
the other Maxwell equations.

Mesh refinement compares \(u_h,u_{h/2},u_{h/4}\) after interpolation into a common typed space.  Exact equality,
resolution equality, and uncertainty compatibility remain separate.  Observed convergence order is estimated only
for compatible nested families and must stabilize with decreasing raw differences and a demonstrated error bound.
Refinement without such evidence does not produce a continuum solution.

\paragraph{Worked example 1: one-dimensional penetration model (physics).}
For a half-space idealization,
\[
                         B''(x)=\lambda_L^{-2}B(x),\qquad
                         B(0)=B_0,\quad B(x)\to0\text{ as }x\to\infty,
\]
the model solution is \(B(x)=B_0e^{-x/\lambda_L}\).  A finite-domain numerical experiment replaces infinity with a
declared truncation boundary and reports truncation, mesh, solver, material-parameter, and measurement uncertainties.
Agreement with exponential decay tests this model within the apparatus range.

\paragraph{Vacuum draw: Brownian reconciliation and its missing limit.}
The Brownian experiment isolates the deterministic skeleton of a diffusion story.  Its setup consists of a finite
ring of integer-mass cells and a stencil \(q=(q_L,q_R)\in\mathbb Z^2\).  The executable transform is not a stochastic
path generator; it is
\[
 T_B(q,\mathcal L)=\operatorname{decide}(q_L=q_R),
\]
where the ledger argument records setup but is not consumed by \texttt{run}.  The canonical stencil \((1,1)\)
returns true; the upwind control \((0,1)\) returns false and exposes the no-drift hypothesis.  Separate theorems,
included as claim-level evidence rather than run steps, give \(q_R-q_L=0\) and \(q_L+q_R=2q_L\) under symmetry and
show that appending the two parts of a split three-cell ring preserves record count.  Thus the run stops after one
finite coefficient-equality decision; there is no random seed, time step, tolerance, or mesh-refinement loop.

The canonical cells carry masses \(1,-1,2\), but \texttt{count\_append} proves
\(3=2+1\), the number of cell records.  It does not prove conservation of their folded integer mass, much less a
probability normalization.  The source defines \texttt{totalMass}, yet that function is not a conjunct of \texttt{claim\_holds}.
Calling the append theorem mass conservation would promote stored mathematical vocabulary into a consumed
dependency, exactly the error this chapter's ledger is meant to catch.
Nor does symmetry alone define an update of the ring: \texttt{Setup.ring} is carried but \texttt{run} consults only the stencil.
Changing every cell mass leaves the Boolean unchanged.  Any prose about redistribution must therefore be graded as a
model description until an actual state-update function consumes those masses.

No centered-second-difference square is available here.  The source stores only the two neighbor weights and proves
their equality, signed no-bias identity, and balanced sum; it supplies neither a center coefficient nor a state-update
operator to which \(u_{i+1}-2u_i+u_{i-1}\) could be compared.  Such an operator would be a new construction, not a
commuting map already witnessed by the run.  The stronger arrows to \(u_t=D u_{xx}\), a central-limit theorem,
Brownian randomness, or Schr\"odinger evolution likewise do not exist: no \(D\), \(\hbar\), probability law, or limit
is represented.  The evidence is coefficient symmetry and ledger-count bookkeeping only.

\paragraph{Vacuum draw: a reciprocal oscillator step is not its continuous flow.}
The harmonic experiment uses the effect-specific domain
\(H=\mathbb Z^2\) of states \((x,p)\) and parameters \((\alpha,\beta)\in\mathbb Z^2\).  Its declared state transform is
\[
 T_H^{\alpha,\beta}(x,p)=(x+\beta p, p-\alpha x),
\]
the forward-Euler shadow of \(\dot x=\beta p,\ \dot p=-\alpha x\).  The exported run projects a setup to the Boolean
turning-point test \(p=0\).  With \(\alpha=\beta=1\), the run accepts \((3,0)\) and rejects \((3,1)\); it ignores the
stored oscillator field.  Origin fixation is a separate theorem about \(T_H\), not something the run verifies.  Another
claim-level finite transform maps a level \(n\in\mathbb N\) to \(2n+1\); it reads \(1\) at the ground level and is
strictly increasing when its precondition \(n_1<n_2\) holds.  Equality of levels is its explicit failure control.

One arithmetic row makes the noncommutation concrete.  The canonical update sends the turning state
\((3,0)\) to \((3,-3)\).  Its doubled action changes from \(9\) to \(18\), even though the continuous oscillator with
the corresponding quadratic Hamiltonian conserves action.  The mismatch is not rounding: it is the first-order
update's truncation behavior.  A symplectic or exact rotation step would be a different transform with its own trace,
stability region, and cost.
Mapping \((x,p)\) into the continuous phase-plane notation makes the update equations agree for one Euler step, but
the action \(\alpha x^2+\beta p^2\) is not exactly conserved by that step.  This claim-level calculation therefore
refuses the commuting claim ``finite step equals continuous flow.''  Additive ledger count is another separate
theorem, not a run output; the failed action-conservation square remains visible.

\paragraph{Vacuum draw: Casimir boundary counts before pressure.}
The Casimir setup is a finite cavity \(C=(m,r)\in\mathbb N^2\), where \(m\) is the number of available mode slots and
\(r\) the count suppressed in the interior.  Its transform constructs two ledgers,
\[
 T_C(m,r)=\bigl([0,\ldots,m-1],\ [i<m:r\le i]\bigr),
\]
then runs the strict comparison \(|\mathrm{interior}|<|\mathrm{exterior}|\).  The meaningful preconditions are
\(0<r\le m\).  At the canonical input \((8,3)\), the exterior trace has eight slots, the interior five, and the run
returns true.  At \((8,0)\), both counts are eight and it returns false.  Suppression is thus a consumed input, not a
word attached after the calculation; values with \(r>m\) retain natural-number truncation and fall outside the
physical cavity reading unless separately governed.

The retained slots are \(3,4,5,6,7\).  A lone Boolean erases the imbalance, and suppressing a noninitial set would
require a different mask rather than this prefix filter.

The cardinality map commutes with the finite claim: removing at least one valid slot makes the surviving set smaller.
No map sends that difference to force or the Casimir pressure law; plate spacing, a boundary eigenproblem, zero-point
spectrum, units, and \(d^{-4}\) scaling are absent.  This blocks the inference but does not negate the physical effect.

\paragraph{Counterexample 2: labels do not establish a PDE.}

\paragraph{Worked example 3: verification versus validation (physics).}

\section{Iteration and slicing in the field report}

A field-shaped numerical report is a dependency ledger, not a physical field.  Its data flow is
\[
\begin{array}{c}
\text{raw indexed samples and coordinates}\\
\downarrow\\
\text{domain, order, spacing, and boundary validation}\\
\downarrow\\
\text{stencil coefficient generation}\\
\downarrow\\
\text{coefficient--sample products and second differences}\\
\downarrow\\
\text{ratio, reciprocal, scaled-floor, and display slices}\\
\downarrow\\
\text{solver states and mesh-refinement comparisons}\\
\downarrow\\
\text{error estimates and uncertainty propagation}\\
\downarrow\\
\text{validation rows and certified report}.
\end{array}
\]
Every arrow is typed, budgeted, and replayable.  Skipping an arrow does not inherit its guarantees.

For stencil index \(k\), the consumed row is
\[
S_k=(i_-,i_0,i_+,x_-,x_0,x_+,f_-,f_0,f_+,c_-,c_0,c_+,d_k),
\]
with
\[
                         d_k=c_-f_-+c_0f_0+c_+f_+.
\]
The report records where each coordinate, value, and coefficient came from.  Coefficients stored elsewhere but not
used in these three products are not part of this result.  Conversely, an unrecorded multiplier makes arithmetic
replay incomplete even if the final numeral looks plausible.

Exact rational outputs use normalized ledgers \((n_k,d_k^\ast)\) with \(d_k^\ast>0\); the symbol \(d_k^\ast\) here
denotes a denominator and is distinct from the stencil result above.  Ratio slices compute Euclidean quotient and
remainder, scaled-floor slices compute
\[
n_kM=Q_{k,M}d_k^\ast+R_{k,M},\qquad0\leq R_{k,M}<d_k^\ast,
\]
and reciprocal slices require \(n_k\ne0\).  Denominator zero rejects the ratio record; numerator zero rejects only
the reciprocal slice.  A display retaining \(Q_{k,M}\) but dropping \(R_{k,M}\) is explicitly lossy.

Iteration and slicing play different roles.  Index traversal iterates overlapping stencils.  A linear or nonlinear
solver iterates state vectors and residuals.  Mesh refinement iterates discretizations and comparison maps.  Slicing
projects one state or report into endpoint, quotient, residual, display, constraint, or uncertainty views.  A slice
cannot replace the iterative trace that produced its source.

The dependency graph has nodes for raw samples, calibration and coordinate transforms, boundary data, coefficients,
products, sums, normalized ratios, projections, solver states, refinement transfers, error estimates, and validation
claims.  An edge records operation, units, arithmetic model, version, and consumed inputs.  Claims are licensed only
by reachable, validated ancestors.  Orphan metadata and cyclic provenance are rejected.

The replay algorithm topologically orders the graph, validates node schemas and edge domains, recomputes each
deterministic operation, and compares stored outputs.  It then replays solver and refinement sequences in their
declared order, verifies stops and budgets, and evaluates claim slices.  External or nondeterministic observations are
read from the receipt rather than recomputed and carry their acquisition provenance.

\paragraph{Worked example 1: replayed stencil to display (computation).}
For uniform samples \((0,1,4)\), consumed coefficients \((1,-2,1)\) give second difference \(2\).  Store this as
exact ratio \(2/1\), scale by \(M=100\), and obtain \(Q=200,R=0\).  The path from samples to display is replayable.
Keeping only label \(2.00\) erases indices, coefficients, exact arithmetic, scale residue, and route.

\paragraph{Counterexample 2: stored stencil, different consumed inputs (computation).}
A row advertises coefficients \((1,-2,1)\), but its trace multiplies \((1,-1,0)\) by the samples.  Coefficient
metadata passes a presence check while consumption replay fails.  The result cannot be certified as a second
difference.

\paragraph{Counterexample 3: slice-specific domain failure (computation).}
A stencil output exactly equal to zero forms valid ratio \(0/1\), quotient, remainder, and scaled-floor slices.
Its reciprocal is undefined.  The report marks only the inverse row failed; it does not discard the valid source
ledger or invent infinity.

\paragraph{Worked example 4: refinement iteration and uncertainty (computation).}
Let compatible meshes produce \(u_h,u_{h/2},u_{h/4}\).  Transfer them into a common typed space, retain raw
differences, estimate observed order only under a declared same-family error model, and combine demonstrated
discretization and arithmetic bounds with input uncertainty.  A decreasing residual and stable observed order support
the declared numerical claim; they do not validate a physical model.

\paragraph{Vacuum draw: the continuum-limit experiment factors through the coarse mesh.}
Here the device itself supplies the finite transform.  The setup domain is a natural mesh level \(s\); \texttt{coarsePath}
maps \(0\) to the all-origin path, \(1\) to the node-one displacement, and every \(s\ge2\) to node two.  With the
fixed active pair, the performed transform is
\[
 T_L(s)=\operatorname{pairDelta2}(\operatorname{coarsePath}(s),
                                  \operatorname{pairVariation}(\mathrm{node1},\mathrm{node2})),
\]
and the three explicitly proved sample rows read \(T_L(0)=-1\), \(T_L(1)=1\), \(T_L(2)=0\).  The exported \texttt{run}
only returns the integer \(T_L(s)\); the separate experiment predicate compares that return with the piecewise
\texttt{expectedStress}.  Both functions are total on every natural level, and every input above two selects the final
path.

Levels \(2\), \(3\), and \(300\) are distinct setups in one definitional fiber: all select the node-two path and
return \(0\).  That equality is not convergence, nor does the total run report refinement failure.

This is precisely where transform and projection must not be confused.  Define the exact truncation
\(q(s)=\min(s,2)\).  Directly from the cases of \texttt{coarsePath},
\[
             \operatorname{coarsePath}(s)=\operatorname{coarsePath}(q(s)),
             \qquad T_L(s)=T_L(q(s)).
\]
This exact factorization through a three-element image is many-to-one, with no internal inverse or sequence
