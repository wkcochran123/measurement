Agent protocol
==============

Audience
--------
All agents write for the manuscript "The Grammar of Measurement" in TeX and
7-bit ASCII.

Forbidden manuscript moves
--------------------------
- Do not mention Lean.
- Do not mention code as code.
- Do not say that an implementation "does" the plot.
- Do not hide behind implementation vocabulary when grammar vocabulary is
  available.
- Do not use Unicode characters in TeX output.

Required manuscript stance
--------------------------
- Explain what the grammar permits, forbids, identifies, quotients, carries,
  measures, or makes unreadable.
- State why the plot point is forced by those grammatical obligations.
- Use examples from device/Experiments only as concrete illustrations.
- Preserve claim discipline: forced grammar, carried structure, or interpretive
  reading.

Manager duties
--------------
- Write or update a local status.txt before and after each child task.
- Keep child tasks small enough to merge by hand.
- Merge child output into the parent TeX file.
- Leave notes in manager_notes.txt explaining integration choices.
