\chapter{Scope}
\label{chap:scope}

% Closed question: What kind of claim can a name carry?

A class name is where the argument becomes sayable.

Before an aircraft leaves the gate, the crew runs through a list: flaps, trim,
fuel, clearance, runway, weather, final readiness. Each name is brief. Each name
points to a state that must hold before the next state can be trusted. If the
crew cannot confirm one item, the aircraft does not take off.

The list is tiny compared with the aircraft. That is why it matters. A
complicated apparatus becomes publicly usable only when its obligations can be
called, answered, and checked. The checklist does not contain the aircraft. It
names the gates by which the aircraft is permitted to move.

This book treats the project's class names in the same way. They are not
decorative labels pasted onto code. They are public callouts for obligations the
argument must satisfy. Chapter 2 walks the full procession. This chapter explains
what sort of work a name can do before the procession begins.

\section{The Name As Instrument}
\label{se:the-name-as-instrument}

People trust names every day before they trust proofs.

A runway number, a calibration sticker, a boarding pass, a medication label, a
courtroom role, a fuse rating: each is short enough to be used under pressure,
and specific enough to change what may happen next. The name is not the whole
truth about the thing. It is an instrument that lets a larger apparatus act.

The pre-flight checklist makes this concrete. ``Flaps set'' is not a description
of aerodynamics. It is the public handle for a physical configuration, an
indicator reading, a training procedure, and a certification regime. The captain
does not call the mechanism. The captain calls the name. The name is useful
because the crew already knows which obligation sits behind it. The whole
apparatus moves because a small public word has been answered.

A class name works the same way. \lean{DISTINGUISHABLE} does not contain the
whole formal definition of distinguishability. It calls that obligation into
the current context. Once the obligation is present, later code and later
prose may move. If the obligation is missing, the next move is not licensed.
The class name is a small object that lets a large argument proceed.

A second example, away from cockpits and code, will be useful before the
procession begins. A pharmacy bottle on the counter carries a drug name, a
strength, a date, a patient name, and a barcode. None of those is the
chemistry. Together they are the instrument by which the pharmacist may hand
the bottle across. Without the names the chemistry cannot be safely
transferred. With the names a stranger can complete the transfer in seconds.
The chemistry is private to the laboratory. The names are the public surface
that lets the transfer happen at all.

An instrument can fail. A checklist can be falsified, a label can be wrong, a
class instance can satisfy an interface while betraying the intended meaning.
That possibility does not make the name ornamental. It makes the named
obligation inspectable. A bad name hides the failure. A good name gives a
reader somewhere to look. The pharmacist who notices a mismatched barcode and
stops the dispense is doing exactly what a good name was built to permit. The
copilot who calls back a flap setting that does not match the indicator is
doing the same.

The first claim is therefore modest. Names are instruments because they expose
the conditions under which action is allowed. The next section asks what those
conditions cost.

\section{The Name As Obligation}
\label{se:the-name-as-obligation}

A good name makes evasion harder.

If a process is called \lean{REPEATABLE}, the reader knows what must be shown:
the reading has to survive being done again. If a process is called
\lean{HALTED}, the reader knows what cannot be left open: the process must
have reached a recognizable output. If a conclusion is called \lean{INFERRED},
guessing is not enough; the conclusion must be licensed by a record.

The pre-flight checklist makes this ordinary. ``Fuel checked'' owes more than
a confident nod. It owes a quantity, a unit, a route plan, and a reserve.
``Clearance received'' owes an actual clearance, not a feeling that the
runway is probably available. The name is short because the procedure is
long. The procedure is long because the obligation is real.

The canonical case in this project is calibration. A reading without a named
reference is not yet a reading. In the Lean code, \lean{LOGICAL} carries
\lean{ekg : Calibration.EKG}. That field matters rhetorically before it
matters technically. Logic is not free-floating cleverness. It carries a
scale. The underlying reference remains hidden from the program that uses it,
but the certificate of calibration is public. The name exposes the obligation
while the reference itself stays protected.

A second example, away from cockpits and code. A hospital medication order
carries a drug, a dose, a route, a frequency, and an indication. The nurse
preparing the dose does not have to retrace the prescriber's reasoning. The
nurse has to check the five named obligations against the patient: right
patient, right drug, right dose, right route, right time. The five checks
are five named gates. Each gate may refuse. The order moves only when each
gate has been answered.

A name as obligation has to be named in advance, publicly held, and small
enough to fail. A private standard invented at the moment of use is not an
obligation. A public standard that never refuses anything is not an
obligation either. The project's class names matter because they can refuse.
They let the reader ask: where is the witness, where is the gate, where is
the calibration, where is the halt?

\section{The Name As Public Argument}
\label{se:the-name-as-public-argument}

A private proof can be correct and still fail to persuade the public.

The public does not need the entire proof at every moment of action. A bridge
sign does not print the engineer's calculations. It says the bridge has a
load rating under a named standard. A patient wristband does not print the
hospital's database. It gives the nurse a name, a barcode, and a number that
can be checked against the order. The public sentence is short because the
discipline behind it is long.

The rhetorical gauge asks whether the formal sequence has become sayable in
that way. It does not simplify by removing rigor. It lets the right names
carry the right pressure.

The first three names already show the form. \lean{DISTINGUISHABLE}: the
mark can be told apart. \lean{ADMISSIBLE}: the distinguishable mark may
enter under rule. \lean{COUNTABLE}: the admitted mark can take a place in a
sequence. No definition has been quoted yet, but the order can already be
heard. The next name is forced by the previous one. Difference without
admission is noise. Admission without count is a pile. Count without
encoding will not travel.

A second example. A courtroom moves only when each named role is answered:
judge, jurors, plaintiff, defendant, counsel, witness, bailiff. The trial
is not the names. The trial is what the named roles, taken in their order,
are licensed to perform. A trial conducted without a named judge is not a
trial. A trial conducted without sworn witnesses is not a trial. The names
are the public surface that lets the proceeding count as the kind of thing
the law recognizes.

That is the method of the book. It follows the necessary names until the
record can license a public sentence. The running case will be a used-car
inspection: a buyer, a seller, a mechanic, and a decision about whether
money should change hands. The decision is small enough to remain ordinary
and large enough to make the whole procession necessary.

\begin{handoff}

The checklist showed that named gates already govern public action. The used-car
inspection will now run the same discipline in order. The question is no longer
what a name can carry in general. The question is what sentence the full
procession of names can license.

\end{handoff}
