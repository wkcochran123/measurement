\chapter{Source Registry}
\label{chap:source-registry}

This first attempt uses the shared bibliography from the instrument book and a
local Volume 6 bibliography for historical entries not already present there.
The final source pass should turn this registry into an episode-by-episode
checklist.

\section*{Episode Source Requirements}
\addcontentsline{toc}{section}{Episode Source Requirements}

Each final episode must verify:

\begin{enumerate}
\item the date and location of the experiment or publication;
\item the apparatus and what it could actually record;
\item the observation reported at the time;
\item the refusal or boundary the record imposed;
\item the later reinterpretation, if any;
\item which claims in this volume are primary-source supported and which rely
on canonical secondary history.
\end{enumerate}

\section*{Current Draft Status}
\addcontentsline{toc}{section}{Current Draft Status}

The current manuscript is a compact architectural attempt. It has all six
movements in place and uses the required \lean{phenom} kernel. It is not yet a
publication source pass. The climate, Standard Model, cosmology, LHC trigger,
and discovery-threshold sections especially require full source review before
expansion.
