# The Positron Threshold Effect

The apparatus resolves the admitting tilt for a positron only at tag resolution.
At the symmetric baseline, the antimatter count is zero.  At the first tilted
configuration, the antimatter count is at least one.  The exact continuum
crossing is below the device resolution, so the device brackets the threshold
instead of pretending to compute it exactly.

The experiment proves the bracket `(0, 1]` in tag-strain units and records the
knot estimator from the two straddling readings:

- before knot: strain 0, stress -1
- after knot: strain 1, stress +1
- fitted crossing: strain 1/2

This replaces a biased linear least-squares reading.  The point of the
experiment is that a kinked stress-strain curve must be measured by the
false-before-after-true knot pattern; ordaining a Hooke-style line bakes in the
wrong convergence law.
