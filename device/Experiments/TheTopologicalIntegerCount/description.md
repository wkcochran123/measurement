# The Topological Integer Count

Source: `instrument/chapters/10.tex:772`
Environment: `phenomenon`
Original title: `The Topological Integer Count`

## Description

Under sufficient informational stress, a continuous current reveals itself as
a discrete set of causal threads.  These threads are counted by topological
winding number and are necessarily integer-valued.

No fractional thread is admissible.  The ledger either contains a thread or
it does not.  Quantization is therefore not mysterious, but required by the
integrity of the causal record.
