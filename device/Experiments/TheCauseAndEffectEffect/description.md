# The Cause-Effect Effect

Source: `instrument/chapters/07.tex:611`
Environment: `phenomenon`
Original title: `The Cause--Effect Effect~\cite{wigner1960}`
Labels: `ph:cause-effect-effect`

## Description

\textbf{Statement.}
Admissible causal records admit predictive structure far tighter than would
be expected from unconstrained combinatorics.

\textbf{Description.}
If events were connected only by arbitrary correlation, the number of
admissible futures would grow exponentially with refinement depth.
Instead, admissibility collapses the space of futures into a narrow set of
predictable continuations.

\textbf{Interpretation.}
This compression is not imposed by external law, but is forced by the
requirement of global consistency within the causal ledger.

The appearance of reliable cause-and-effect is therefore not miraculous.
It is the combinatorial residue of admissibility itself.
